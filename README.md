# Minecraft Mods (Fabric 26.3)

Each folder is one mod. GitHub Actions builds them all automatically on every change.

**Getting the jars:** Actions tab → latest run with a green tick → Artifacts → `mod-jars` → unzip → drop the `.jar` into your Modrinth profile (needs Fabric API).

## Mods
- **poplar-arrow** – Arrow + poplar leaves = Poplar Arrow. Normal arrow damage, plus autumn leaves pile up around the target's screen (stacks up to 3 hits).
- **dappled-fox** – A horse-sized fox that spawns in the Dappled Forest. Tame it with sweet berries (1-in-3 chance per berry), saddle it and ride it; while riding, your attack becomes the fox's bite (6 damage + half your weapon). Berries heal it and breed two tamed foxes. Comes in orange, red (uncommon) and yellow (rare); kits take after a parent. Test: `/summon dappledfox:dappled_fox`, or `/summon dappledfox:dappled_fox ~ ~ ~ {Variant:1}` for red, `{Variant:2}` for yellow
