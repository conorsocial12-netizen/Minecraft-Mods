# Minecraft But Better

A selection of mods that make vanilla Minecraft look and feel better. Each folder is one mod (Fabric 26.3, needs Fabric API).

## Mods
- **3d-skin-layers** – Skin overlays (hat/hair, jacket, sleeves, pants) become real 3D pixels instead of flat panels. `/skinlayers` opens the settings (also in Mod Menu). Client-side, works on any server.

Jars are built automatically along with the rest of the repo: Actions tab → latest green run → Artifacts → `mod-jars`.
